# Scene3D

Decoders for the 3D formats found in PDF documents, producing a format-neutral scene that is ready to
upload to a GPU.

| Project | Purpose |
|---|---|
| `Scene3D` | Scene model, limits, GLB (binary glTF 2.0) writer |
| `Scene3D.U3D` | Reader for Universal 3D (ECMA-363) files |

Status: early development. See the tests for what is covered.
